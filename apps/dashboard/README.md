# Milens Desktop Dashboard

Visualize your milens code intelligence data in a native desktop app.

## Features
- **Overview** — Project stats at a glance
- **Domains** — Module cluster visualization
- **Learning** — Annotation trends and confidence distribution
- **Metrics** — TER, LR, CQI, BRR, TCGR, DCER, CTR
- **Security** — Scan results and vulnerability timeline
- **Settings** — Profile management and hook configuration

## Development
```bash
npm install
npm run dev
```

## Build
```bash
# Build for current platform
npm run build

# Build for all platforms
npm run build:all
```
