Per-Platform Details

Pick your harness. Keep your workflow.

Each platform gets its own MCP config, install command, and integration depth. Full means all 43 tools + 6 hooks + 6 skills. Partial means growing — adapters in active development.

⚡
Claude Code Full
milens serve -p .
Config: .claude/mcp.json

Deepest integration. All 43 tools, 6 hooks, 6 skills, full learning pipeline.

◆
OpenCode Full
npx milens init --profile full
Config: opencode.json

Native MCP config. AGENTS.md auto-generate. Full tool access.

◈
Codex Full
npx milens init --profile full
Config: .codex/config.json

App + CLI parity. Shared skills and commands across surfaces.

▣
Cursor Full
npx milens init --profile full
Config: .cursorrules

OSS config compatibility. Read .cursorrules alongside AGENTS.md.

◎
GitHub Copilot Partial
npx milens init --adapter copilot
Config: .github/copilot-instructions.md

MCP tools via adapter. 30+ tools available. Growing support.

◇
Gemini Partial
npx milens init --adapter gemini
Config: .gemini/config.json

Adapter pack available. CLI tool access. MCP protocol support.

▨
Zed Partial
npx milens init --adapter zed
Config: .zed/settings.json

MCP protocol support. Adapter in active development.
