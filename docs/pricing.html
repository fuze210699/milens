Decision Guide

Choose the right path.

Three clear paths — pick the one that matches where your team is today.

Stay on Free if…

You work on public, open-source repositories. You need all 41 MCP tools, 7 sub-agent prompts, and 50+ security rules — without paying a cent. You're fine with 10 GitHub App analyses per month and community support.

Buy Pro if…

You work in private repositories and need the GitHub App to auto-review PRs and run security scans on every push. You want 50 analyses per seat per month, priority support, custom skill packs, and a billing portal for team management.

Talk to Enterprise if…

You need SSO/SAML, audit logging, on-prem deployment, custom rules, SLAs, and rollout consulting. Procurement and governance are part of the job, and you need a dedicated partner to roll Milens across the organization.

The Delta

What changes when you pay.

Three dimensions unlock as you move up. Each tier builds on the one before it — nothing is taken away.

Repository scope

Public → Private

Free covers public repos only. Pro and Enterprise unlock private repositories — the full codebase, not just what's open. Your proprietary code gets the same intelligence layer as OSS.

Automation layer

Manual → Auto-triggers

Free gives you manual CLI runs. Pro adds the GitHub App with PR auto-review, scheduled analysis, and CI/CD hooks. Enterprise adds custom rule engines that trigger on your policies.

Operational support

Community → Priority

Free gets community forums and docs. Pro adds Slack/email priority support. Enterprise gets a dedicated support engineer, SLAs with uptime guarantees, and rollout consulting.
